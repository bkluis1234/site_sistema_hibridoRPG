Caminhos de API são relativos a apps/api/src; web a apps/web/src. Prioridades P0 = proteção/integridade essencial, P1 = qualidade operacional, P2 = expansão. Prioridades novas desta matriz são decisões de engenharia, não novas regras de RPG.
